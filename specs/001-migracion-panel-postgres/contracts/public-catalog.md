# Contract: Public Catalog and WhatsApp Flow

The public behavior remains available without authentication. The data source changes from Strapi to PostgreSQL and the image source changes to the new object storage.

## Public Routes

| Route | Contract |
|---|---|
| `/` | Shows published and active products, existing filters, availability, images and access to details/favorites. It must show useful loading, empty and error states. |
| `/productos/:publicId` | Resolves the preserved product identifier used by current public links. Published/active products show full details, ordered images and size stock. Missing or unavailable products receive a controlled response. |
| `/cart` | Resolves the visitor's locally stored product IDs through the application, displays current product data and prepares the WhatsApp message. |

## `POST /api/cart-details`

Request:

```json
{ "ids": [12, 18, 24] }
```

The numeric values remain the preserved legacy product IDs used by the current browser store. The server validates that the body is a bounded array of positive integers, queries PostgreSQL, returns current normalized product data and never exposes database credentials.

Success with products:

```json
{ "data": [/* normalized public products */], "missingIds": [] }
```

Success with an item no longer available:

```json
{ "data": [/* available products */], "missingIds": [24] }
```

An empty list returns `{ "data": [], "missingIds": [] }`. Database failures return a user-safe `5xx` response; the cart page must explain that it could not refresh the selection.

## Public Product Shape

The UI-facing shape keeps the current concepts while removing Strapi-specific nesting:

```json
{
  "id": 12,
  "documentId": "preserved-public-id",
  "Tipo": "Bata",
  "Fabricantes": "Fabricante",
  "Marca": "Marca",
  "Genero": "Unisex",
  "Precio": 25.5,
  "SKU": "SKU-12",
  "Color": "Blanco",
  "Talla": [{ "id": 1, "Talla": "M", "cantidad_actual": 3 }],
  "Foto": [{ "id": 1, "url": "https://new-storage/...", "alternativeText": "...", "position": 0 }]
}
```

No public route may call Strapi at runtime. A product is marked available only when it is published, active and has positive stock in at least one size.

## WhatsApp Invariant

The message generated by `/cart` must be derived from the same current records returned by `POST /api/cart-details`. It must not include an item reported in `missingIds` without an explicit user-facing warning, and it must preserve the current selected product information used by the business flow.
